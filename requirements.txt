# optional) dependency on `cryptography` (imported unconditionally at
# module load, for encrypted-PDF support -- not just for encrypted files),
# with `cffi` as cryptography's own build/runtime dependency. Left
# unpinned, these resolved to nothing at all in at least one deployment
# environment and pip silently fell back to an incompatible system-level
# `cryptography` package with a broken compiled backend -- every PDF
# upload (invoices, bank statements) failed at the `import pdfplumber`
# line inside validate_financial_file, before any of Baseera's own code
# ran. Pinning forces pip to install a known-good matched pair instead of
# an ambiguous transitive resolution.
